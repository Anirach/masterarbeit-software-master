Unterstützte Dateiformate: JSON (.json), PDF (.pdf)

Hinweise zum Import

  • JSON-Dateien müssen im korrekten Format vorliegen (exportiert aus diesem System).
  • PDF-Import ist eine experimentelle Funktion und kann bei komplexen PDFs fehlschlagen.
  • Die importierten Aufgaben werden der Kurseinheit Kurseinheit hinzugefügt.
  • Bestehende Aufgaben werden nicht überschrieben.

Informationen zum Import

So funktioniert der Import

Importieren Sie Aufgaben einfach aus einer vorhandenen JSON- oder PDF-Datei:

JSON-Import

JSON-Dateien können aus diesem System exportierte Aufgaben enthalten. Der Import unterstützt:

  • Einzelne Aufgaben
  • Mehrere Aufgaben in einer Datei
  • Komplexe Aufgaben mit Teilaufgaben

PDF-Import (experimentell)

Der PDF-Import versucht, Aufgaben aus PDF-Dateien zu extrahieren. Diese Funktion ist experimentell und kann bei komplexen PDFs zu unerwarteten Ergebnissen führen.

Tipp: Verwenden Sie zum Exportieren von Aufgaben den Export-Button auf der Kurseinheit-Seite oder auf der Aufgaben-Detailseite.
