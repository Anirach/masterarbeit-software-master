Kurs importieren

Importieren Sie einen Kurs aus einer Datei. Der Import umfasst den Kurs mit allen Kurseinheiten, Materialien und Aufgaben.

Datei für Import auswählen

Bitte wählen Sie eine Datei aus.
Unterstützte Dateiformate: JSON (.json), ZIP (.zip)

Hinweise zum Import

  • JSON-Dateien müssen im korrekten Format vorliegen (exportiert aus diesem System).
  • ZIP-Dateien sollten eine kurs.json-Datei und zugehörige Materialien enthalten.
  • Der importierte Kurs wird als neuer Kurs angelegt, bestehende Kurse werden nicht überschrieben.
  • Der Import kann je nach Größe des Kurses einige Zeit in Anspruch nehmen.

Informationen zum Import

So funktioniert der Import

Importieren Sie Kurse einfach aus einer vorhandenen JSON- oder ZIP-Datei:

JSON-Import

JSON-Dateien können folgende Elemente enthalten:

  • Kursdaten mit Namen
  • Kurseinheiten mit Reihenfolge
  • Kursmaterialien (Base64-kodiert)
  • Aufgaben mit Teilaufgaben

ZIP-Import

ZIP-Archive sollten folgende Struktur haben:

  • kurs.json - Die Kursdaten im JSON-Format
  • Zusätzliche Dateien für Kursmaterialien
Tipp: Exportieren Sie zunächst einen bestehenden Kurs, um das erforderliche Format zu sehen.
